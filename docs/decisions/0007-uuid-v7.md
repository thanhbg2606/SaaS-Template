# ADR-0007 — Khóa chính: UUID v7

**Status:** Accepted

**Context:** Auto-increment lộ số lượng record và khó merge cross-tenant/cross-service. UUID v4 ngẫu nhiên gây phân mảnh index. Cần ID sắp xếp được theo thời gian.

**Decision:** **UUID v7** cho mọi khóa chính (sortable theo thời gian → PK + thứ tự thời gian trong một cột, không cần index `created_at` để sort). Laravel 11+ dùng `HasUuids` (sinh UUID v7 mặc định). API trả **prefixed display ID** (`proj_…`, `inv_…`) qua serializer; DB lưu UUID thô.

**Consequences:**
- (+) Không lộ business metric; thân thiện index; dễ debug khi khách paste ID.
- (−) Khóa 16 byte (lớn hơn bigint) — chấp nhận được với index tốt.
