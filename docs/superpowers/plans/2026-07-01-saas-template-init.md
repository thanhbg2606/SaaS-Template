# SaaS Template Init Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn this repository into a runnable Laravel React/Inertia SaaS template that reaches a real Docker/Sail-based `Dev ready` state.

**Architecture:** Scaffold a standard Laravel starter app first, then layer in the template's `Kernel/Product` boundaries, product configuration, demo data, and architecture enforcement. Keep the application as a Modular Monolith with native template boundaries, `deptrac` enforcement, and seams based on contracts and domain events rather than a module package.

**Tech Stack:** Laravel 12 starter kit, React 19, Inertia 2, TypeScript, Tailwind 4, shadcn/ui, Laravel Sail, PostgreSQL, Redis, Mailpit, Pest, Deptrac

- [ ] **Step 3: Add the initial Deptrac ruleset**

Create `deptrac.yaml`:

```yaml
deptrac:
  paths:
    - ./app
  layers:
    - name: Kernel
      collectors:
        - type: directory
          value: app/Kernel/.*
    - name: Product
      collectors:
        - type: directory
          value: app/Product/.*
    - name: Controller
      collectors:
        - type: classLike
          value: .*Controller.*
    - name: Service
      collectors:
        - type: classLike
          value: .*Service.*
    - name: Repository
      collectors:
        - type: classLike
          value: .*Repository.*
  ruleset:
    Kernel: ~
    Product:
      - Kernel
    Controller:
      - Service
    Service:
      - Repository
      - Kernel
      - Product
    Repository: ~
```

- [ ] **Step 4: Add a Composer script for architecture checks**

Modify the `scripts` section in `composer.json` to include:

```json

  "deptrac": "vendor/bin/deptrac analyse",
  "check": [

  ]
}
```
