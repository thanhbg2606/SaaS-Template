# 31. Customer Support & Success

### 31.1 Stack support ngày đầu

Email `support@` → ticketing (Plain/HelpScout/Front) · in-app chat (Intercom/Crisp) · docs search được · status page · community (chỉ khi có bandwidth).

### 31.2 Hook support vào sản phẩm

Nút "Get help" mở chat với URL trang hiện tại · nút "Copy debug info" (workspace_id, user_id, browser, version, request_id của lỗi cuối) · trang lỗi kèm `request_id` + link contact support.
