# 23. Internationalization & Accessibility

### 23.1 i18n từ ngày đầu — kể cả khi chỉ ship tiếng Anh

Hoãn việc thêm ngôn ngữ; đừng hoãn **plumbing**. Bọc mọi chuỗi user-facing trong helper dịch. Laravel: `__('key.name')` + lang file (`lang/vi.json`, `lang/en.json`). Tránh nối chuỗi — dịch giả cần câu đầy đủ. ICU MessageFormat cho số nhiều/giống.

### 23.2 Format theo locale

Date: `Intl.DateTimeFormat` / Carbon localized. Số/tiền: `Intl.NumberFormat`. **Lưu UTC, render local.**

### 23.3 Accessibility (WCAG 2.2 AA)

Mọi element tương tác reach được bằng bàn phím · focus state nhìn thấy · ARIA label cho icon-button · HTML semantic (`<button>` không phải `<div onClick>`) · contrast ≥ 4.5:1 · test `axe-core` trong CI.
